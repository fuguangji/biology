# 生物遊戲專案

這是一個基於 Scratch/TurboWarp 打包的瀏覽器遊戲專案，主要內容是以「生物」為主題的互動式遊戲，並以 HTML + JavaScript 方式執行。

## 專案概述

本專案的核心檔案如下：

- `index.html`：遊戲入口頁面
- `script.js`：遊戲執行與啟動程式碼
- `assets/project.json`：專案實際內容資料，包含舞台、角色、變數與腳本邏輯

從程式結構來看，這個專案是由 Scratch 專案轉成 TurboWarp 包裝版本，使用者可直接在瀏覽器中開啟並執行。

## 遊戲內容

從專案資料中可觀察到以下角色與元素：

- `Stage`：舞台
- `Sprite1`：主角色/主要控制單位
- `food`：食物元素
- `HUNTER`：敵對/捕食角色
- `HUNTER2`：輔助或第二種敵對角色

此外，也有幾個關鍵變數，例如：

- `hp`：生命值
- `hunger`：飢餓值
- `speed`：速度
- `v gene`：基因/變異相關數值

這代表遊戲可能包含補給、生命管理、移動與生存/競爭機制，屬於生物模擬或生存型小遊戲。

## 啟動方式

### 方法 1：直接開啟瀏覽器
1. 進入專案資料夾
2. 雙擊開啟 `index.html`
3. 在瀏覽器中等待遊戲載入完成

### 方法 2：透過本機伺服器開啟
如果你的瀏覽器在直接打開時有相容性問題，可以使用簡單的靜態伺服器啟動，例如：

```bash
python -m http.server 8000
```

然後在瀏覽器網址列輸入：

```text
http://localhost:8000
```

## 使用說明

- 打開頁面後，通常會出現綠旗啟動按鈕
- 按下綠旗後遊戲會開始運行
- 根據遊戲內容進行互動、移動與判定
- 如需調整遊戲內容，請修改 `assets/project.json` 或相關 Scratch 專案來源

## 開發與維護

這個專案的本質是 Scratch 專案轉成 HTML 包裝版本，較適合使用以下方式維護：

- 直接修改 Scratch 原始專案後重新匯出
- 調整 `assets/project.json` 內的設定與腳本
- 修改 `script.js` 以改善載入或互動行為

## 注意事項

- 此專案是前端瀏覽器型遊戲，通常不需要額外安裝依賴
- 因為是打包的 TurboWarp 專案，部分檔案是產物，不一定適合直接手動編輯
- 若要進一步修改遊戲內容，建議回到 Scratch/TurboWarp 專案原始來源

## 結論

這是一個以「生物」為題材的互動式遊戲專案，結合 Scratch 腳本邏輯與瀏覽器執行環境，適合用來展示、遊玩與進一步擴充。
